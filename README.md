# BallGame（壁面投影ボール当てゲーム）

壁にプロジェクターで映像を映し、ボールが当たった位置に花や演出を出す設置用アプリです。
Kinect v2 の深度だけを使って、ボールが壁に当たった位置を見つけます。

- Unity 6（6000.4.0f1）／URP／新しい Input System のみ
- シーンは `Calibration`（校正）のあとは、`Christmas`（クリスマスツリー）・`Game`（草原）・`Autumn`（紅葉の山）を **ランダムな順** に替えて遊ぶ（同じ場面が2回つづくことはない）
- 画面（UI）は実行時に 1920×1080 の Canvas で組み立てます

---

## 1. はじめに用意するもの

| もの | 説明 |
| --- | --- |
| Kinect v2 と PC 用アダプター | 深度センサー |
| Kinect for Windows Runtime 2.0 | `Kinect20.dll` が入ります（Microsoft のサイトから入手） |
| プロジェクター | 壁に映します |

Kinect が無い PC でも動きます。そのときは 320×240 の「模擬深度」に自動で切り替わり、Game 画面のクリックがボールになります。

---

## 2. 校正のしかた（現場の画面だけで完結）

Unity で `Assets/Scenes/Calibration.unity` を開いて再生します（ビルドしたアプリは最初にこの画面が出ます）。

1. **設置を選ぶ**
   - 「横に設置」（初期値）：Xbox ロゴが操作者側を向く置き方。画像の下が近く、上ほど遠い。
   - 「真下に設置」：壁の真下から上を見る置き方。画像の上が近く、下ほど遠い（見やすいように表示だけ上下を入れ替えます）。
   - 選んでいる方のボタンが緑になります。同じボタンを押し直しても四隅と基準は消えません。別の設置に切り替えたときだけ消えます。
2. **左のプレビューで四隅をタップ**
   - 左上 → 右上 → 右下 → 左下 の順にタップします。間違えたら「四隅をやり直す」。
3. **人がいない状態で「基準を録る」**
   - 30 フレーム録って、画素ごとの中央値を基準にします（全部 0 のフレームは数えません）。
4. **「ゲームへ」**

そのほかのボタン：

- **左右反転**（初期オン）：画像を左右反転します。四隅と基準も一緒に反転します。
- **入力源**：Kinect／模擬 を切り替えます。
- **壁からの距離**：これより壁から離れた物は無視します（初期 15cm、5〜80cm）。
- **リセット**：2 回押すと、四隅・基準・しきい値・左右反転・入力源・設置向きをすべて消して最初からにします。

校正は自動で保存され、Game から戻ったときと次回起動時に元に戻ります。
保存先は `Application.persistentDataPath/ballgame_calibration.bin` です。

## 3. クリスマスの場面（Christmas）

- 校正画面の「ゲームへ」で始まります。
- ボールが壁に当たるたびに、当たった所から飾りが飛んでいき、ツリーに 1 つずつ付きます。飾りは、いろいろな色のボールと赤い電球（3 個に 1 個）です。電球は消えた状態で付き、☆が付いた瞬間にいっせいに点いて、ぴかぴか光り始めます。
- 当たりは **1 秒に 1 個**まで数えます（弾んだボールで何度も数えないため）。
- 画面の左に「あと 〇こ！」を出します。**10 回目**にてっぺんの **☆** が付いて完成です。
- 完成したら、ツリーのまわりに「きらきら～」と光の演出を出し、「**クリスマスツリーの完成～！**」を 3 秒出します。
- そのあと「つぎは おはなばたけ！」と **10 秒のカウントダウン**（きらきらは続きます）を出して、草原の場面（Game）へ移ります。
- 子ども向けに、文字は大きく、ひらがなを多く、教科書体のフォント（Windows の UD デジタル 教科書体）を使っています。
- スペースキーで、左下の係の人用の表示（飾りの数・最大の塊・校正へ戻る）を隠せます。
- 3D の部屋が使えるときは、テスト用に **T キー** で「ボールが1球当たったこと」にできます（Kinect なしで確かめるとき用）。

## 4. 草原の場面（Game）

- 四隅で囲った範囲が、背景画像いっぱいに引き伸ばされます（壁座標は左下 (0,0)、右上 (1,1)）。
- 背景は草原（Background_02_Meadow）に固定して始まり、壁の**どこに当たっても花**がにょきっと生えます（演出設定の flowerBoundary を 1 にしています。0.5 にすると、下半分は花・上半分は演出に戻ります）。
- 上部の操作：背景の選択（◀ ▶）、ランダム、固定、切替間隔（初期 5 分、60 秒〜1 時間）、壁からの距離、校正へ戻る。
- **スペースキー** で、上部の操作・HIT 表示・校正へ戻るボタン・壁からの距離をまとめて隠します（もう一度押すと出ます）。
- 当たるたびに、Kinect 上の位置（0〜1）、壁の位置（0〜1）、Unity の画面座標をコンソールに出します。
- ボールが **10 回**（1 秒に 1 回まで数えます）当たると「おはなが いっぱい！」を出し、10 秒のカウントダウンのあと、次の場面（ランダム）へ移ります。

## 4-1. 紅葉の山の場面（Autumn）

- 最初は緑の山の絵です（画像ファイルは使わず、プログラムで描きます）。
- ボールが当たった場所から、赤・だいだい・黄色の紅葉が円のように広がります（約 4 秒）。当たるたびに葉が舞い上がります。
- 山の 90% が紅葉したら、残りがいっせいに色づいて完成です。「もみじの やまが できた！」を 3 秒出し、「つぎは ○○！」（次の場面の名前）と 10 秒のカウントダウンのあと、次の場面（ランダム）へ移ります。
- 完成しなくても 10 分たつと移ります（次の 4-2 と同じ規則）。Ｔキーでテスト用に 1 球当たったことにできます。

## 4-1b. シャボン玉割りの場面（Bubble）

- 空にシャボン玉（大きさ・色いろいろ、**15 個**）がふわふわ浮かび、ボールが当たると「パチン！」と割れます（音と輪・水しぶきの演出つき）。
- **1 回は 15 秒**です。右上に残り秒、左上に割れた数を出します。割った玉は補われません。割りそびれた玉は、上へ出ても下から戻ってきます。
- 15 個すべて割れた（または 15 秒たった）ら、割れた数に合わせた結果を **5 秒** 出して、すぐ次の回を始めます。
  - 15 こ：「15こ われたよ！やったね！」
  - 10〜14 こ：「Nこ われたよ！　おしかったね！」
  - 1〜9 こ：「Nこ われたよ！まだまだこれから！」
  - 0 こ：「0こ だったよ！つぎはがんばろう！」
- これを場面に入ってから **15 分** たつまで繰り返します。15 分を過ぎたとき遊んでいる回は、結果を見せ終えるまで続け、そのあとで次の場面（ランダム）へ移ります（最後の結果のとき「つぎは ○○！」を出します）。
- 玉に当たらなかったときは、小さく光るだけです。F5 の固定モード（玉は割れず時間も進まず、ボールの位置の赤い輪だけ出る）は、ほかの場面と同じです。Ｔキーで画面のどこかに 1 球当たったことにできます。
- 絵と音はすべてコードで作っています（画像や音のファイルは増えません）。

## 4-2. 場面の切り替え（ランダム）

クリスマス・草原・紅葉の山は、次の **どちらか早いほう** で、次の場面へ移ります。次の場面は、今の場面以外の 2 つからランダムに選びます（`SceneRotation`）。

1. ボールが **10 回** 当たったとき（クリスマスは星が付いたあと、草原は「おはなが いっぱい！」のあと、紅葉の山は全体が紅葉したあと）。移る前に 10 秒のカウントダウンを出します。
2. 場面に入ってから **10 分** たったとき。終わりの 10 秒前からカウントダウンを出します。

ただし、10 分の **最後の 1 分** にボールが当たったときは、切り替えを **さらに 1 分** のばします（のばしたあと、また残りが 1 分以内になって当たれば、もう 1 分のびます）。
操作パネル（スペースキーで出し入れ）に、場面が替わるまでの残り時間を出しています。10 分・1 分・10 秒は `SceneTimer`（`Scripts/Runtime/Game/SceneTimer.cs`）の既定値です。

---

## 4-3. 固定モード（F5）

**F5 キー** で「いまの場面をずっと続ける」固定モードを入り切りできます（場面をまたいでも状態は続きます）。

- 場面の切り替えをしません（10 分の時間切れも、回数による完成後の移動もなし）。カウントダウンも出しません。当たった数も数えません。
- **エフェクト・飾り・花・紅葉・葉は出しません。** そのかわり、いまボールが検知されている場所に **赤い輪** を出します（ボールが動けば輪も動き、見えなくなると約 0.35 秒で消えます）。検知の確かめ用です。
- 輪は、ボールとして採用できる塊（校正画面で赤く出るもの）の重心の位置です。模擬深度のときは、画面をクリックするとその場所に出ます。Ｔキーでも出せます。
- 操作パネル（スペースキーで出し入れ）に **「固定モード：ON / OFF」ボタン** と、操作用の文に「固定モード」の表示が出ます。ボタンを押しても F5 と同じです。子どもに見せたくないときは、スペースキーでパネルごと隠せます。もう一度 F5（またはボタン）で元に戻ります（戻したとき、すでに当てた数が決まりの回数を超えていれば、次の 1 回で完成します）。

## 5. 画像と演出の入れ替え

| 置き場所 | 内容 |
| --- | --- |
| `Assets/Textures/Backgrounds` | 背景画像。名前順に使います。入れると `Resources/BackgroundCatalog` が自動で更新されます（ビルド用）。 |
| `Assets/Textures/Flowers` | 花の画像（透過 PNG 推奨）。自動で Sprite として取り込みます。 |
| `Assets/BallGame/Settings/GameEffectSettings.asset` | 演出設定。Game シーンの `GameBootstrap` に割り当て済み。 |

演出設定（インスペクタで変更）：

- **flowerBoundary**：花と演出の境目（初期 0.5）
- **themes**：背景ごとの花（複数）と演出（複数）。`backgroundName` に背景のファイル名を書くとその背景に使います。
  演出を空にすると、背景 1 は輪・閃光・粒、背景 2 は二重・波紋・十字、背景 3 は渦・花びら・閃光粒です。
- 同時表示は最大 24、色は紫、表示倍率 1.25、再生 1 秒（すべて変更可）。演出は終わったら破棄します。
- **flowerDisplaySeconds**：花が出てから消えきるまでの表示時間（初期 3 秒。1 秒で伸び、最後の 0.5 秒で消えます）

同梱の背景 3 枚と花 3 枚は動作確認用の仮の画像です。

## 6. 検知のしくみ（要点）

- 四隅の内側だけを見て、基準深度と今の深度を比べます。
- Kinect は壁に沿って見るので、奥行きの差ではなく「四隅の基準から作った壁の面までの垂直距離」で判断します。
  壁の向きは画素ごとに基準深度の周りから求めます（壁の奥では視線と壁の角度が数度しかなく、1 枚の平面では向きのわずかなずれで距離が大きく狂うため）。求められない所は四隅の内側全体に当てはめた平面の向きを使います。
- 基準を録るときに画素ごとの揺れ幅も記録し、しきい値は「ノイズ床（初期 45mm、校正画面で変更可）」と「揺れ幅×3（ノイズ床の 2 倍まで）」の大きい方にします。壁からの距離（初期 15cm）より遠いものは捨てます。
- 校正画面で **Ｆ９キー** を押すと、プロジェクトの `_diagnostics` フォルダに診断（`diag_日時.txt` と `preview_日時.png`）を保存します。「この場所でボールが反応しない」ときの原因調べ用で、四隅の内側を横 10 個の帯に分けて、基準の深度が取れているか・揺れているか・検知に必要な高さ・壁を見る角度、直近の塊の位置と不採用の理由を書きます。右側だけ反応しないときは、右側へボールを数回当ててから押してください。
- 校正画面のプレビューで **紫** になっている所は、基準の深度が取れていない（または基準を録る間に揺れた）画素で、ボールを検知できません。割合も下の状態欄に出ます。ボールが消える場所があれば、そこが紫か確かめてください（紫なら、設置の向きや壁の反射を見直すか、基準を録り直します）。
- 校正画面のプレビューでは、**ボールとして検知できた塊を赤**（消えたあとも約 0.6 秒残します）、それ以外の変化は琥珀色で表示します。人サイズの塊があるフレームでは赤を出しません。
- 基準があった画素が 0 になったときは、赤外線が返らない物体として候補にします（基準を録る間に 0 になったことがある画素は除く）。
- しきい値を超えた点を芯にして、つながっている「しきい値の 5 割以上」の弱い変化も塊に含めます（ボールの縁を拾うため）。
- 3×3 で孤立した芯は捨て、4 連結の塊にします。塊の中で一番強い点がしきい値の 1.15 倍未満のもの、縦横の箱の 2 割未満しか埋まっていないまばらなものは捨てます。
- 大きさは画素数ではなく、深度から求めた**実際の大きさ**で比べます（「Kinect から 2m の所での画素数」に直した値。近い所は1画素が小さく、遠い所は大きいため）。
- 面積（2m 換算）12 未満（約 3.6cm²）は捨て、24 以上（約 7cm²、または一番強い点がしきい値の 2 倍以上）は 1 フレームで採用、それ以外は 2 フレーム続いたら採用します。
- 校正画面の右下と Game の HIT 表示に「最大の塊 面積・強さ・詰まり（不採用の理由）」が出ます。現場での調整に使ってください。
- 変化した面積の合計（2m 換算）が 4500（約 1360cm²）を超える、または縦横が 80（約 44cm）を超える塊があるときは「人」とみなし、ボールは出さず、去ったあと 0.5 秒待ちます。
- 同じ場所に留まった物体は出し続けません。ヒット位置は塊の重心です。

## 7. テスト

Unity の **Window → General → Test Runner → EditMode** で実行します。
校正の保存、設置の上下関係、背景の切替、花と演出の選択、壁の面までの距離、人サイズの除外、クリスマスの流れ（15 回で完成 → 5 秒 → 3・2・1）を確かめます。

## 8. フォルダ構成

```
Assets/
  BallGame/
    Scripts/Runtime/   … ゲーム本体（Core / Depth / Detection / Session / Game / Christmas / Autumn / Effects / UI / Screens）
    Scripts/Editor/    … 背景カタログの自動更新、画像の取り込み設定
    Settings/          … 演出設定（ScriptableObject）
    Tests/EditMode/    … Edit Mode テスト
  Resources/           … ビルド用の背景カタログ
  Scenes/              … Calibration.unity / Christmas.unity / Game.unity / Autumn.unity
  Textures/            … Backgrounds / Flowers
```
